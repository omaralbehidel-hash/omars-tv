# OMAR'S TV — تطبيق Android TV أصلي

لوحة ليلية للتلفزيون: ساعة، تاريخ هجري وميلادي، مواقيت الصلاة، طقس، بث مباشر وراديو، مؤشر صوت حقيقي، ووضع نوم بمؤقّتات.
تطبيق **أصلي** (Kotlin + Media3 ExoPlayer) بلا واجهة ويب؛ قنوات يوتيوب تُشغَّل عبر مشغّل يوتيوب الرسمي المضمَّن.

## التحميل
أحدث ملف APK: صفحة **Releases** ← الوسم `latest` ← `OMARS-TV.apk` (يُبنى تلقائيًا عند كل تحديث على `main`).

## التثبيت على التلفزيون
- **Downloader** أو **Send Files to TV**: أرسل/نزّل الملف ثم افتحه (فعّل «مصادر غير معروفة» عند الطلب).
- أو ADB: `adb connect IP:5555` ثم `adb install -r OMARS-TV.apk`.

## التحكم بالريموت
أسهم للتنقل، **موافق** للتشغيل، **رجوع** للإغلاق/الرجوع، **القائمة** للإعدادات.

## البناء
`./gradlew assembleDebug` (JDK 17 وAndroid SDK 34). ملف `.github/workflows/emulator.yml` يختبر التطبيق على محاكي Android TV.

## نسخة الويب
المجلد `docs/` (GitHub Pages) يحوي نسخة الويب القديمة، والمصدر في `web-src/` و`web/`.
