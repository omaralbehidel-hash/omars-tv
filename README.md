# OMAR'S TV — تطبيق Android TV

لوحة ليلية للتلفزيون: ساعة، تاريخ هجري وميلادي، مواقيت الصلاة، طقس، بث مباشر وراديو، ووضع نوم.
مبني بـ Kotlin (غلاف WebView) وواجهة HTML/CSS/JS داخل `app/src/main/assets`.

## 1) الحصول على ملف APK (أسهل طريقة، بدون تثبيت أي برنامج)
1. أنشئ مستودعًا خاصًا (Private) على GitHub وارفع محتويات هذا المجلد كما هي.
2. افتح تبويب **Actions** ← **Build OMAR'S TV APK** ← **Run workflow**.
3. بعد دقائق نزّل الملف من **Artifacts** باسم `OMARS-TV-apk` (يحتوي `app-debug.apk`).

### أو من جهازك (Android Studio)
افتح المجلد في Android Studio ← انتظر مزامنة Gradle ← **Build ▸ Build APK(s)**.
أو من الطرفية: `./gradlew assembleDebug` (يحتاج JDK 17 وAndroid SDK 34).
الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## 2) التثبيت على التلفزيون (Xiaomi / Google TV / Android TV)
- **الطريقة الأسهل:** ثبّت تطبيق **Send Files to TV** على الهاتف والتلفزيون، أو **Downloader** على التلفزيون، وأرسل ملف APK ثم افتحه.
  (فعّل «مصادر غير معروفة» للتطبيق المستخدم عند الطلب: الإعدادات ▸ الأمان والقيود.)
- **أو عبر ADB:** فعّل خيارات المطور وتصحيح USB/الشبكة ثم:
  `adb connect IP_التلفزيون:5555` ثم `adb install -r app-debug.apk`
- يظهر التطبيق باسم **OMAR'S** في قائمة التطبيقات بشعارك.

## 3) القنوات
- القناة التي لها رابط **تعمل تلقائيًا** عند فتح التطبيق (آخر قناة شاهدتها).
- القنوات الفارغة تعرض زر **إضافة الرابط**؛ الصق الرابط مرة واحدة ويُحفظ.
- روابط YouTube المدعومة: رابط فيديو/بث مباشر `watch?v=…` أو `youtu.be/…` أو `youtube.com/live/…` أو رابط قناة بصيغة `youtube.com/channel/UC…` (يفتح البث المباشر الحالي للقناة).
- بعض القنوات تمنع تشغيل بثها خارج يوتيوب؛ عندها ستظهر رسالة واضحة، استخدم رابط البث الرسمي المتوافق (`.m3u8`) إن وفّرته الجهة.
- الراديو: ألصق رابط البث الصوتي المباشر (mp3/aac/m3u8).
- لا يستخرج التطبيق تدفقات YouTube بأي طريقة غير رسمية، ولا يتجاوز قيود مالكي المحتوى.

## 4) الخدمات الخارجية
| الخدمة | الاستخدام | المفتاح/التكلفة |
|---|---|---|
| Aladhan API | مواقيت الصلاة | مجانية، بلا مفتاح |
| Open-Meteo | الطقس | مجانية للاستخدام غير التجاري، بلا مفتاح |
| YouTube Embedded Player | تشغيل قنوات يوتيوب | رسمي، بلا مفتاح، ويخضع لشروط يوتيوب ومالك القناة |
> إن كان استخدامك تجاريًا فراجع شروط Open-Meteo وAladhan. لا توجد مفاتيح سرية داخل التطبيق.

## 5) أزرار الريموت
الأسهم للتنقل · OK للاختيار · Back للرجوع/الإغلاق (ضغطتان من الشاشة الرئيسية للخروج) · Play/Pause للتشغيل والإيقاف المؤقت · Channel +/- للتنقل بين القنوات.
في ملء الشاشة: ▲▼ للقناة السابقة/التالية، ◄► للصوت، OK للإيقاف المؤقت.
في وضع النوم: ▲▼ لضبط السطوع، OK أو Back للخروج.

## 6) قيود معروفة
- لا يتحكم التطبيق بسطوع لوحة التلفزيون نفسها؛ وضع النوم يخفض سطوع عناصر الواجهة فقط.
- استمرار الصوت في وضع النوم يعتمد على الجهاز والمصدر (يعمل عادة لأن الفيديو يبقى قيد التشغيل خلف الشاشة السوداء).
- المؤشر الصوتي يتحرك فقط عندما يوفّر المصدر بيانات صوتية فعلية (راديو/HLS مع CORS)، وإلا يعرض «المؤشر غير متاح لهذا المصدر».
- «التشغيل عند بدء الجهاز» قد لا يعمل على Android 10+ بسبب قيود النظام على تشغيل الواجهات من الخلفية.
- الواجهة عربية فقط في هذا الإصدار.
